# Domaine de l'Aubrée (site de démonstration)

Site vitrine et boutique d'un **domaine viticole fictif**, réalisé comme démonstration. Les noms, chiffres, vins et prix sont inventés ; aucune commande, réservation ni inscription n'est réellement envoyée.

## Contenu
- 10 pages : accueil, le domaine, nos vins, fiches vins, visites, journal et articles, contact, mentions légales, CGV, cookies
- Panier persistant, filtres et tri, réservation de visite, contrôle d'âge, bandeau cookies (refus aussi simple que l'acceptation)
- HTML, CSS et JavaScript sans dépendance ni étape de build

## Structure
- `index.html` : page d'entrée
- `css/site.css` : styles
- `js/data.js` : contenu (vins, articles, visites)
- `js/app.js` : navigation entre pages, panier, formulaires
- `img/` : photos en WebP, plusieurs tailles
